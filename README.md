# Stroke-Prediction-Analysis---Mini-Project
An end-to-end healthcare analytics project analyzing stroke risk factors and patient characteristics. Data cleaning and transformation were performed using Advanced Excel and Power Query, followed by interactive visualization and insight generation in Power BI.
Project Overview

The project covers the complete data analytics workflow:

Data Cleaning → Transformation → Analysis → Visualization → Insights

Advanced Excel – Data cleaning, validation, and initial manipulation
Power Query – Data transformation, feature engineering, and preparation
Power BI – Data modeling, interactive visualization, and insight generation
DAX – Measures and KPI calculations
Analysis Covered

The dashboard explores stroke patterns across:

Age and age groups
Gender
Hypertension
Heart disease
BMI and BMI categories
Average glucose level
Smoking status
Work type
Residence type
Marital status

Power BI Dashboard

The dashboard provides an interactive view of:

Overall stroke distribution
Patient demographics
Health and lifestyle factors
Stroke-related patterns across different segments
Key insights derived from the analysis


Tools Used

Microsoft Excel | Power Query | Power BI | DAX
